# @owmo/engine

TypeScript framework for constructing canvas-based rendering pipelines; realtime, frames and/or data. The project aims to be suitable for web-based algorithmic art, procedural design, and media rich experiences.

## v0.x.x (Alpha)

Please **DO NOT** use this in a production environment prior to a 1.0 release; there will be breaking changes between minor versions. The package is being developed in service to my personal algorithmic / interactive art practice, and so I make no promises of support. I invite you to visit my studio website and browse the artwork made using this framework:

https://www.owmo.studio/
